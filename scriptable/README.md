# Defender 2025 ウィジェット（iPhone／Scriptable）

燃料残量・航続距離・ロック状態・オドメーター・ナンバー・最終確認日時を、中サイズのホーム画面ウィジェットに表示します。タップすると、設定したショートカット経由でRemoteを開きます。

**これは手入力版です。Remoteからの自動取得は実装していません。** Remoteの画面を見て入力し、更新時にも同じ操作が必要です。車内温度は表示しません。

## 1. スクリプトを登録

1. App Storeから「Scriptable」をインストールします。
2. 添付の `Defender.js` をダウンロードします。Scriptableに読み込むか、ファイルの内容をすべてコピーし、Scriptableの「＋」で作った新しいスクリプトに貼り付けます。
3. スクリプト名を `Defender` にして保存します。
4. 実行（▶︎）して「ナンバー・起動設定」を選び、ナンバーを設定します。ナンバーは空欄でも使えます。
5. もう一度実行し「車両情報を入力・更新」でRemoteに表示されている数値を入力します。距離はすべてkm、燃料は%です。空欄は「—」表示になります。
6. 次の画面で、その時に確認したロック状態を選びます。未確認なら「不明／未確認」を選びます。

## ディフェンダーの画像を表示

1. 新しい `Defender.js` で、Scriptableに登録したスクリプトの内容を置き換えます。入力済みの車両情報は引き継ぎます。
2. スクリプトを実行し「ディフェンダーの画像を設定」→「写真から選ぶ」を選びます。
3. 自分のディフェンダーの写真、またはiPhoneの写真アプリに保存したディフェンダーの画像を選びます。
4. 画像がウィジェットの背景に表示されます。文字を読みやすくするため、自動的に暗く表示します。

横長で車全体が中央に写った画像がおすすめです。中央を基準にウィジェットの比率に合わせて切り抜くため、端は表示されない場合があります。「画像を外す」で元の緑色の背景に戻せます。

ウィジェット用に縮小した画像だけをScriptableのローカル領域に保存します。写真アプリの元画像は変更しません。画像を変更しても車両情報の最終確認日時は変わりません。ホーム画面への反映にはiOSの更新待ちが発生する場合があります。

## 2. Remoteを開くショートカットを作る

1. iPhoneの「ショートカット」アプリで「＋」をタップします。
2. アクション「Appを開く」を追加します。
3. 開くアプリに、普段使っているLand Roverの `Remote` アプリを選びます。
4. ショートカットの名前を **Remoteを開く** にします（空白なし）。
5. 一度実行し、Remoteが開くことを確認します。

ウィジェットは `shortcuts://run-shortcut?name=...` でこのショートカットを実行します。Remote固有の未確認URLスキームは使いません。起動時にショートカット画面が一瞬表示されたり、iOSから初回の許可を求められたりする場合があります。ロック中は解除が必要な場合があります。

## 3. ホーム画面に追加

1. ホーム画面の空いている場所を長押しし、ウィジェット追加を開きます。
2. `Scriptable` の **中サイズ（横長）** を追加します。
3. 追加したウィジェットを長押しし「ウィジェットを編集」を開きます。
4. Scriptに `Defender` を選びます。Parameterは空欄です。
5. タップしてRemoteが開くことを確認します。

## 更新とロック状態について

- 更新するときは、Scriptableから `Defender` を実行して「車両情報を入力・更新」を選びます。
- 保存した時刻を「確認日時」として記録します。車両の通信時刻を取得したものではありません。
- ロック表示は「施錠（確認時）」「解錠（確認時）」「不明」です。現在の状態を保証しません。施錠・解錠の操作はしません。
- 確認から1時間を過ぎると「古い情報」と表示し、ロック状態は「施錠（過去）／解錠（過去）」になります。ただし表示が切り替わる時刻はiOSの更新タイミング次第です。
- 再描画の希望間隔は15分ですが、実際のタイミングはiOSが決めます。再描画しても入力した値は自動更新されません。手入力直後のホーム画面への反映も遅れることがあります。
- データはScriptableのKeychainに保存します。このスクリプトにネットワーク送信処理はなく、InControlのID・パスワードも不要です。ナンバーはホーム画面上に見えるので、必要に応じて一部を伏せて入力してください。
- 削除する場合はスクリプトを実行し「保存データを削除」を選びます。

## 自動取得について

iPhone単体から最新の車両データを安定して取得する方法は、今回確認できていません。旧来のライブラリjlrpyは、JLR側のアクセス制限により実質動作しないと案内されています。Home Assistant用の非公式連携には読み取り機能が案内されていますが、追加システムが必要で、この手入力版には含めていません。2025年式のご本人のディフェンダーやiPhoneでの実機確認は未実施です。
